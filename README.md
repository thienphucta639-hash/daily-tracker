# 📅 Daily Tracker

Ứng dụng theo dõi hoạt động hàng ngày - bữa ăn, công việc, chi tiêu.

## 🚀 Deploy lên Vercel (Cực kỳ đơn giản!)

### Cách 1: Deploy nhanh
1. Fork repo này về GitHub của bạn
2. Vào [vercel.com/new](https://vercel.com/new)
3. Import repo → Click **Deploy**
4. Xong! 🎉

### Cách 2: Push code mới
1. Push code lên GitHub
2. Vào [vercel.com/new](https://vercel.com/new) → Import repo
3. Click **Deploy**
4. Xong! 🎉

**Không cần cấu hình gì thêm!** Dữ liệu lưu trên localStorage của browser.

## 💻 Chạy local

```bash
npm install
npm run dev
```

Mở http://localhost:3000
